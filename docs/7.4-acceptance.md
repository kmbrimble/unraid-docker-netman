# Unraid 7.4 acceptance checklist (run before tagging anything from `feature/native-extranetworks`)

Needs a real Unraid 7.4 host (rc.2 or later) with a disposable test container on a user-defined
network; never a real service. Rollback: reinstall the previous release; templates written by `save`
stay valid.

1. **Baseline.** Note `cat /etc/unraid-version`. Confirm the control exists:
   `grep -c contExtraNetworks /usr/local/emhttp/plugins/dynamix.docker.manager/include/CreateDocker.php` is > 0.
2. **Install** this branch's build (`plugin install` of the branch's `.plg`/`.txz`). Check
   `/var/log/plugins/docker.netman.plg` and the installed tree.
3. **Native row hidden.** Open Docker -> Add Container (and Update Container on the test container).
   - "Additional Networks" label, widget and its help text are not visible; "Network Type" and
     "Fixed IP" rows are intact and unmoved. If any of it shows, capture
     `document.querySelector('#contExtraNetworks').closest('dl').outerHTML` and the next sibling's
     `outerHTML` — that is the real DOM the injector's assumptions (see CLAUDE.md) must be corrected to.
   - NetMan's "Additional networks" section is present.
   - `scripts/browser-check.js` on `/Docker/UpdateContainer?...`: zero page errors.
4. **Import.** In a scratch template set `<ExtraNetworks>proxynet</ExtraNetworks>` (or create it natively
   on an unpatched 7.4 box first), open Update Container: exactly one NetMan row `proxynet`, no IP/alias/MAC.
5. **Save moves it.** Add a second network in NetMan with a fixed IP, click Apply. Read the template back:
   `<ExtraNetworks/>` empty (or `<ExtraNetworks></ExtraNetworks>`); ExtraParams/PostArgs holds BOTH
   networks; no other element changed (diff against a pre-edit copy).
6. **Force Update recreate.** Docker -> test container -> Force Update (or
   `scripts/rebuild_container <name>`). Then `docker inspect <name>` shows both networks, the fixed IP as
   `IPAMConfig.IPv4Address`, and the update log has NO "Could not connect one or more additional networks".
7. **Overlap warning.** Hand-edit the template so one network is in both `<ExtraNetworks>` and NetMan's
   block. Settings -> Docker NetMan: row shows the red "in both native field and NetMan" chip and
   warning; the container is not auto-modified. Click Save in the editor: warning clears.
8. **7.3.x regression (separate 7.3 host/pass).** No native control: Add/Update pages look exactly as
   before; no elements hidden; `contExtraNetworks[]` absent from the posted form.
9. **Fail soft.** Block `/plugins/docker.netman/include/api.php` in devtools: native control stays visible.
10. Record results (host version, `docker inspect` excerpts, screenshot) in CLAUDE.md under
    "Unraid 7.4", then and only then bump the version and release.
